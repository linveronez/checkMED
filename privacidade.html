Privacidade

Quais dados são usados

O CheckMed pode guardar nome/apelido, medicamentos, horários, estoque, registros de doses, humor, anotações, perguntas para consultas, compromissos e informações de contato preenchidas por você. O PIN, permissões/estado de notificações e metadados de backup permanecem no aparelho e não fazem parte do snapshot de sincronização. A preferência para ocultar nomes nas notificações está incluída no snapshot, conforme o contrato da API.

Armazenamento local e conta

Sem conta, os registros são guardados no armazenamento do navegador deste aparelho. O navegador ou sistema pode apagá-los. Se você criar uma conta e aceitar a sincronização, os campos descritos em contrato da API serão enviados ao servidor CheckMed e guardados como um snapshot versionado para restaurar em outro aparelho. A sincronização é opcional. O PIN local não criptografa os dados.

Finalidades e base de uso

Os dados são usados para apresentar a rotina e os registros que você adicionou e, mediante consentimento, para manter uma cópia entre aparelhos. O tratamento de dados de conta e saúde, suas bases legais e os papéis de controlador/operador precisam de validação pelo responsável do projeto antes de uso real. Não use este protótipo para dados de terceiros sem autorização apropriada.

Compartilhamento, terceiros e transferência

Não há compartilhamento familiar implementado. A busca por serviços no SOS pode abrir o Google Maps e links para serviços públicos abrem páginas externas. Ao ativar conta, provedores de hospedagem e banco poderão processar dados para operar a infraestrutura; seus nomes, localidades, contratos e transferências internacionais ainda precisam ser confirmados e informados aqui antes da publicação.

Retenção, cópias e exclusão

Você pode exportar um backup, apagar a cópia da nuvem ou excluir a conta pelo Perfil. Excluir da aplicação não determina por si só o prazo de retenção de backups técnicos dos provedores; confirmar prazos e processo de descarte antes do lançamento. A cópia exportada fica sob seus cuidados. Apagar os dados locais do navegador é uma ação separada.

Segurança e incidentes

A API usa HTTPS quando implantada corretamente, hash de senha, tokens armazenados como hash no banco e controle de versão para conflitos. Isso não elimina todos os riscos. O processo de atendimento a solicitações de titulares, incidentes, retenção de logs e contato de privacidade ainda deve ser definido pelo responsável antes de uso público.

Crianças e adolescentes

Este rascunho não define regras suficientes para uso por crianças ou adolescentes. Público, consentimentos e salvaguardas precisam ser avaliados antes de permitir esse uso.
